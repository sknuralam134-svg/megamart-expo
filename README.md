# MegaMart

Cross-platform e-commerce app built with **Expo (React Native)**.

Works on:
- Android
- iOS
- Web

## Theme
- Primary Color: Green (`#2E7D32`)
- Background: White / Light Gray

## How to run (Mobile)

1. Install **Expo Go** app from Play Store / App Store
2. Install Node.js on a computer (or use Snack)
3. Run:
```bash
npx create-expo-app@latest .
npx expo start
```
4. Scan the QR code with Expo Go

## Features
- Product listing
- Product details
- Add to cart
- Cart management
- Place order (demo)
- Search

## Live Web Preview
After running `npx expo start --web` you can open it in browser.
